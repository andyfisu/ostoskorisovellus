# Shopping Cart Application

A simple C# console application developed as a final project example for the **Introduction to C# Programming** course at Centria University of Applied Sciences.

The application allows users to add products and their prices to a shopping cart, view the cart contents, and calculate the total cost of their purchases.

The project demonstrates basic C# programming concepts, including lists, loops, conditional statements, user input handling, and methods.

The application fulfills the course project requirements.

## Running the Application

The application requires the .NET SDK. Open the project directory in a terminal and run:

`dotnet run`
